1. C'est quoi Dzaryx ?

▶

Dzaryx = assistant IA personnel + business de Fik Conciergerie (Oran, Algérie). Deux patrons l'utilisent : Kouider (à Bruxelles, commercial/réservations) et Houari (à Oran, propriétaire des véhicules, terrain).

Ce n'est pas un simple chatbot : c'est un agent autonome qui gère le vrai business (réservations, finances, parc auto, immobilier), répond à tout comme ChatGPT/Claude, parle darija oranais, génère/édite des images, scanne des pièces d'identité, et pilote même le PC de Kouider.

Les 4 activités de Fik Conciergerie

  • Location de voitures (parc) — réservations
  • Vente de voitures d'occasion
  • Immobilier (location + vente de biens)
  • Commande/import de véhicule sur mesure
Règle d'or : Dzaryx ne ment jamais et n'invente jamais un chiffre. Chaque donnée business vient d'un appel d'outil réel (gardes anti-hallucination).

4. Le cerveau : agents & gardes

▶

Claude est le cerveau. Un routeur choisit un agent spécialisé (sous-ensemble d'outils + prompt dédié) selon les mots-clés du message :

📋 Réservations💰 Finance👤 Clients 📅 Planning🎨 Marketing🎬 TikTok 🧠 Mémoire💻 Code🎨 Designer 🔍 Code Reviewer🌐 Analyse Réseau🎬 Vidéo 🧠 Obsidian🧠 Général (catch-all)

Gardes anti-hallucination (critique)

  • Phantom Guard — bloque une affirmation d'action sans outil write réel.
  • Anti-hallucination — bloque chiffres financiers / dispo voiture / nb résas affirmés sans outil de données.
  • Auto-retry "vrai cerveau" — si une garde bloque, on relance Claude en l'obligeant à appeler l'outil, puis on répond avec les vraies données (au lieu d'un message mort).
  • Bypass : si le contexte a déjà injecté les vraies données (flotte/résas/finance), pas de faux blocage.

Mémoire (réelle, persistante, par-utilisateur)

Table Supabase memory_facts (dedup SHA256, par user_id kouider/houari). Auto-extraction depuis les messages + outils remember_info/recall_memory. Le contexte ré-injecte les souvenirs pertinents à chaque tour.

5. Langues (le plus important pour Kouider/Houari)

▶

Miroir de langue : Dzaryx répond dans la langue de l'interlocuteur.

EntréeRéponse
FrançaisFrançais (100%, zéro darija parasite)
Darija / arabeDarija ORANAISE — maximum d'arabe, garde seulement les mots français qu'un Oranais dit vraiment (cliene, réservation, acompte). Jamais marocain (pas de ghadi/daba/zwin/dyal), jamais "dima".
Espagnol / AnglaisIdem en miroir

Détection : language-detector.ts — reconnaît la darija latine (arabizi : "gouli kach jdid", "3andek", "ch7al") via ~200 tokens + détection chiffres-lettres (3=ع,7=ح,9=ق).

Voix

  • STT : OpenAI gpt-4o-transcribe (meilleur pour dialectes) → Groq Whisper → Google.
  • TTS : ElevenLabs. Auto-switch de voix : darija/arabe → voix clonée algérienne (ELEVENLABS_VOICE_ID_AR) ; français → voix de base. Arabizi converti en sons avant lecture (3andek→aandek).
Limite connue : la darija PARLÉE reste dure à transcrire parfaitement (aucune IA n'est à 100%). Diction claire + sans bruit = meilleur résultat.

7. Images (génération / édition / dégât)

▶
  • Générer une image neuve → generate_image (gpt-image-1 → DALL-E 3 → Flux).
  • Éditer SA photo / la voiture exacte → transform_image (gpt-image-1 edit ; pour une voiture de la flotte passe car_name → part de la vraie photo Supabase). Garde-fou serveur : photo jointe + "modifie/enlève/mets sur une plage" → édition directe (Claude ne peut pas se tromper d'outil).
  • Estimer un dégât → estimate_damage (Claude vision, photo du choc → coût réparation en DZD).
Le sujet exact à 100% (pixel-parfait) = détourage+composite (Cloudinary) ; le rendu intégré/réaliste = gpt-image-1 (très fidèle mais peut styliser un chouïa).

8. Règles métier finance (CRITIQUE)

▶
Profit = (client_price_per_day − owner_price_per_day) × nb_days. JAMAIS depuis le catalogue. Si owner_price NULL → profit null (jamais inventé).

Qui déduit le prix proprio ?

  • Kouider loue → il loue le véhicule du proprio → marge = (prix client − prix proprio) × jours. Prix client ≥ prix proprio (plancher).
  • Houari loue → c'est LUI le propriétaire → son CA = sa marge complète, rien à déduire.

Devises

  • € : base_price (proprio) / resale_price (client).
  • DZD : le prix par voiture est dans houari_resale_price (affiché "K: … DA" dans PARC). houari_base_price peu utilisé.
  • CA et MARGE sont séparés par devise (€ et DZD). La MARGE est calculée à la volée (pas le champ stocké).
