Développeurs

Intégration en 3 appels API

Ajoutez Dzaryx à votre site ou app en quelques minutes.

// 1. Inscription
POST /api/saas/register
{ "email": "votre@email.com", "business_name": "Mon Business",
  "sector": "car_rental", "city": "Alger", "password": "monmdp" }
→ { token: "eyJ...", org_id: "uuid", ai_name: "Dzaryx" }

// 2. Chat avec l'IA (données business injectées automatiquement)
POST /api/saas/chat
Authorization: Bearer eyJ...
{ "message": "Combien de réservations ai-je aujourd'hui ?",
  "sessionId": "session_123" }
→ { status: "processing" }  (réponse IA en streaming Socket.IO)

// 3. Notifications quotidiennes
GET /api/saas/notifications?unread=true
Authorization: Bearer eyJ...
→ [{ title: "Rapport du lundi 25 mai", body: "...", type: "daily_briefing" }]
