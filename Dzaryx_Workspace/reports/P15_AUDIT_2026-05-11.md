## 1. Architecture P15 — État Réel

```
POST /api/chat
    │
    ▼
processWithOrchestration (orchestrator/orchestrator-engine.ts)
    │
    ├─ 1. checkFocus (focus-manager.ts)
    │      Redis dedup SHA1(session+msg) 10s
    │      rate limit 30 msg/min per session
    │      BLOCKED → error immediately
    │
    ├─ 2. scorePriority (priority-engine.ts)
    │      CRITICAL(10) / HIGH(8) / NORMAL(5) / LOW(2)
    │      telegram +1 boost / backend_internal -1
    │
    ├─ 3. buildOrchestratorContext (context-engine.ts)
    │      channel info + timezone + cross-channel + fleet snapshot
    │
    ├─ 4. routeWithContext (agent-router.ts)
    │      NEXUS prefix → force NEXUS agent
    │      CRITICAL+general → narrow to 10 emergency tools
    │
    ├─ 5. processMessage (conversation/orchestrator.ts)  ← UNCHANGED
    │      Full Claude pipeline: memory + tools + streaming
    │      Tool calls go through executeTool()
    │
    ├─ 6. checkAntiHallucination (anti-hallucination.ts)
    │      Phantom guard + post-check
    │
    └─ 7. logExecutionTrace (anti-hallucination.ts)
           JSON trace: {request_id, channel, priority, latency, ...}

executeTool() (integrations/tool-executor.ts)
    ├─ Calls _dispatch(name, input, sessionId)
    ├─ Measures latency (Date.now delta)
    ├─ isToolFailureResult(result, toolName) → success flag
    └─ recordToolExecution() → Redis action:history:{sessionId}
```

## 8. Known Problems

### P1 — Billing Risk
Telegram session `telegram_809747124` has very long conversation history. Claude API costs accumulate with each message because context is resent. No context pruning in place.

### P2 — Mobile /api/chat tool calls
Fresh sessions via /api/chat don't generate tool calls in action:history. Likely: empty session = no system context = Claude responds without tools. Real usage via mobile app (with proper headers/context) probably works, but can't verify from curl.

### P3 — Semantic dedup impossible
Different phrasings of same fact → 2 rows in memory_facts. Hash dedup only covers case/punctuation variants. Fix = pgvector similarity (complex, not prioritized).

### P4 — content=[binary] in old Redis
Records written before commit 2150911 show content=[binary]. Self-expire in 3600s max. Not a bug — historical records.

### P5 — Focus manager / Priority engine not live tested
These modules produce log output but no live proof of FOCUS_BLOCK or CRITICAL priority boost. Test requires specific message patterns.
